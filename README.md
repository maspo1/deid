# deid
<p align="left">
  <img src="./assets/icon/app.ico" alt="프로그램 로고" width="100">
</p>

**파일 속 개인정보와 민감정보를 찾아 비식별화하는 오프라인 도구**

`deid`는 폴더 안의 파일을 검사해 개인정보와 민감정보를 치환하고, 이미지에서 발견한 정보는 흐림 처리합니다. 파일 내용뿐 아니라 파일명과 폴더명도 처리하며, 작업 내역은 CSV 보고서로 남깁니다.

이름은 vi의 삭제 명령 `dd`에서 아이디어를 얻었습니다. 식별 정보인 ID를 지운다는 뜻을 담았습니다.

Rust로 만든 단일 실행 파일로, 별도의 DLL 설치나 인터넷 연결 없이 동작합니다. 폐쇄망에서도 사용할 수 있습니다.

## 소스 코드 받기

```sh
git clone https://github.com/maspo1/deid
cd deid
```

## 검출 대상

| 구분 | 항목 |
|---|---|
| 개인정보 | 휴대전화번호, 카드번호, 이메일 주소, 주민등록번호, 외국인등록번호 |
| 민감정보 | IP 주소, MAC 주소, 비밀번호, 쿠키, 세션 인증 값, 개인정보·민감정보가 들어 있는 소스코드 주석 |

사용자 정의 정규식으로 검출 패턴을 추가할 수 있습니다. 확신이 낮은 검출 결과는 보고서에 `검토필요`로 표시합니다.

소스코드 주석은 안에 위 정보가 들어 있을 때만 주석 전체를 치환합니다. 평범한 설명 주석은 그대로 두고, 문서 주석 기호(`///`, `//!`, `/**`)는 코드가 바뀌지 않도록 치환하지 않습니다.

## 지원 파일

확장자보다 **파일 시그니처(매직 바이트)**를 기준으로 형식을 판별하므로, 확장자를 바꾼 파일도 실제 형식에 맞춰 검사합니다.

| 형식 | 대상 |
|---|---|
| 텍스트·소스코드 | 일반 텍스트, 소스코드와 주석, JSON, XML, HTML 등 |
| Office 문서 | DOCX, XLSX, PPTX |
| 한글 문서 | HWPX |
| PDF | PDF 문서 |
| 압축 파일 | ZIP |
| 이미지 | PNG, JPG, BMP |

문서에 포함된 이미지와 썸네일도 OCR로 검사하고, 검출된 정보가 있는 영역을 흐림 처리합니다. 결과는 원본의 폴더 구조를 유지해 별도 폴더에 저장합니다.

## 검출 방식

### 1. 비트 병렬 패턴 검사

전화번호, 주민등록번호·외국인등록번호, 카드번호, IP 주소의 형식을 하나의 비트 병렬 상태 행렬(Shift-And)로 동시에 검사합니다.

행렬의 칸에는 올 수 있는 숫자만 넣어 둡니다. 예를 들어 주민등록번호 뒷자리 첫 칸은 1~8, 휴대전화 가운데 번호 첫 칸은 1~9만 허용하므로 존재할 수 없는 번호는 검증 단계까지 가지 않습니다.

주민등록번호의 생년월일은 윤년과 월별 일수를 미리 계산한 날짜표로 확인합니다.

### 2. 규칙 기반 검증

IP 주소의 옥텟 범위(0~255), 휴대전화 식별번호, 주민등록번호 검증 숫자, 카드번호 Luhn·발급사 번호(IIN) 검사 등을 적용해 형식만 비슷한 값을 걸러냅니다. Luhn과 IIN은 미리 계산한 표로 조회합니다.

형식마다 구분자가 올 수 있는 자리(예: 주민등록번호는 6자리 뒤, 카드번호는 4·8·12자리 뒤)를 비트로 미리 구운 **구분자 위치 정답 행렬**과도 비교합니다. 구분자가 빠진 표기는 통과하고, `00013027665 14`나 `250117,250118,2502`처럼 엉뚱한 자리에 구분자가 있으면 탈락합니다.

주민등록번호는 보통의 표기(`YYMMDD-NNNNNNN`)가 아니면 치환하되 `검토필요`로 표시합니다. 카드 맥락 없이 붙여 쓴 카드번호 모양 숫자열도 마찬가지입니다.

### 3. 맥락 기반 판별

`192-168-0-1`, `010_1234_5678`, `010→1234→5678`처럼 구분자가 바뀌거나 생략된 번호는 내장 GBDT 모델이 주변 맥락을 함께 살펴 판별합니다. 모델이 고른 결과도 위의 규칙과 구분자 위치 정답 행렬을 다시 통과해야 검출됩니다.

점(`.`)을 한 가지 규칙으로 일괄 치환한 IP(`103^234^126^56`, `130-170-164-10`, `105 -> 174 -> 171 -> 43`)는 모델 앞단의 표 검사로 판단합니다. 구분자를 원-핫 인코딩 대신 아스키 코드값 그대로 비교해, 세 구분자의 코드가 모두 같으면(XOR 합 0) 같은 규칙으로 봅니다. 4묶음·0~255·장비 주소 대역을 통과하면 확정합니다. 숫자표의 열 구분자(`,` `|` `/` 공백·탭)로만 이은 것은 표 한 줄과 겹치므로 IP 맥락이 있을 때만 표 검사로 확정하고, 맥락이 없으면 모델이 판단합니다. 모델이 '정보 아님'을 골랐어도 구분자가 한 규칙이면 정보 클래스 확률이 0.46 이상일 때 치환하되 `검토필요`로 표시합니다(전화·IP·카드·주민번호 공통). 다른 해석(월·일, 시각, 절 번호 범위, 파일명·버전)이 있는 것은 모델이 맥락으로 판단하고, 기호가 섞인 것(`73,202~66-252`)은 규칙으로 복원하지 않습니다. 전화번호의 하이픈을 `+` `/` `|` 공백 등 한 기호로 바꾼 것도 확정합니다.

레코드 구분자(`,` `;` `|` 공백 `[]` 등)로 이어진 묶음은 레코드마다 떼어서 판별합니다. 프로그램으로 변형한 유출(`88^11^25*1,88&11$25*1`)은 레코드마다 같은 규칙을 따르므로 IP로 복원하고, `21.0.88.11.25.1.7`처럼 숫자 덩어리 안에 묻혀 하나의 규칙으로 떼어낼 수 없는 숫자열은 버립니다.

모델은 구분자를 일부러 빼거나 바꾼 표본과, 프로그램 변형 레코드 묶음, 쪽 범위(`28-35, 97-98`)·PDF 좌표·숫자표·값 변화(`31.6→35.8`)·파일명 같은 함정 표본으로 학습합니다. 처음 학습한 뒤에는 새 seed 로 정답·오답 표본을 만들어 모델이 틀린 것만 골라 학습 데이터에 더하고 다시 학습하는 과정을 3번 반복합니다. 학습과 평가는 다음 명령으로 다시 할 수 있습니다.

```sh
cargo run --release --example train_ml   # 학습 (src/rules/ml/*.txt 갱신)
cargo run --release --example eval_ml    # 재빌드 후 평가: 정형 표기·변형 표기·함정·보고된 오답
```

### 4. 이미지 OCR

숫자·영문·기호에 특화된 자체 경량 OCR로 먼저 읽습니다. 인식 확신이 낮은 줄은 Windows 내장 OCR로 다시 확인합니다.

## 사용법

### GUI

`deid.exe`를 실행하거나, 검사할 폴더를 실행 파일 아이콘에 끌어다 놓습니다.

예를 들어 `애플` 폴더를 검사하면 다음 순서로 진행됩니다.

1. `애플_1번` 폴더에 비식별화 결과와 CSV 보고서를 생성합니다.
2. 결과를 검토하고 승인합니다.
3. 재검사를 거쳐 `애플_검사완료` 폴더로 확정합니다.

### CLI

```text
deid <검사할 폴더> [옵션]
deid --text "검사할 문자열" [--lang 파일명.확장자]
deid --help
```

### CSV 보고서

보고서에는 원본 값, 치환 값, 정보 종류, 파일 경로가 기록됩니다.

```csv
010-1234-5678,***-****-****,휴대전화번호,C:\...\a.log
192.168.0.1,***.***.*.*,IP주소,C:\...\b.pptx
```

## 빌드

**환경:** Windows 10 이상, 64비트, Rust stable

```sh
cargo build --release
```

빌드 결과인 `target/release/deid.exe` 하나만 배포하면 됩니다. `.cargo/config.toml`에서 CRT 정적 링크를 설정합니다.

## 테스트

```sh
cargo test --release
```

테스트 파일과 검출 정답은 `playground/`에 있습니다. 이 폴더에 포함된 개인정보는 모두 시험용 가상 데이터입니다.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `src/rules/` | 검출 규칙: 비트 병렬 상태 행렬, 사전 규칙, 맥락 모델 |
| `src/handlers/` | 형식별 파일 처리: 텍스트, ZIP 계열 문서, PDF, 이미지 |
| `src/ocr/` | 자체 경량 OCR 및 Windows·macOS 내장 OCR 연동 |
| `src/win32_gui/` | Windows 네이티브 GUI |
| `examples/` | 모델 학습 및 성능 측정 도구 |
| `playground/` | 테스트 파일과 검출 정답 |
| `assets/licenses.tsv` | 외부 라이브러리 라이선스 목록 |
